# Python Data Analysis — Sales Dataset

## Project Overview

This project demonstrates a complete Python-based sales data analysis workflow using a synthetic dataset of 300 sales transactions.

The analysis covers:

- Data quality inspection
- Product-wise revenue analysis
- Region-wise revenue analysis
- Product × Region revenue analysis
- Revenue visualization
- KPI extraction
- Business-oriented insights

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## Dataset

The dataset contains 300 synthetic sales transactions with the following fields:

- Product
- Region
- Units_Sold
- Unit_Price
- Revenue

## Key Results

| KPI | Result |
|---|---:|
| Total Revenue | 1,582,649.41 |
| Total Units Sold | 3,083 |
| Top Product | Monitor — 410,560.68 |
| Top Region | North — 464,921.84 |
| Top Product × Region | Monitor + East — 147,489.48 |

## Analysis Workflow

1. Data quality audit
2. Product-wise revenue analysis
3. Region-wise revenue analysis
4. Product × Region analysis
5. Revenue visualization
6. KPI extraction
7. Business insights

## Important Note

This project uses a synthetic dataset for learning and portfolio purposes.

The results do not represent real-world commercial data.
